# Adroit Technologies — Enterprise Web Platform

Official, production-ready corporate web platform for **Adroit Technologies Innovative Solutions Pvt Ltd**. Built using modern frontend architecture to showcase AI-driven software ecosystems, automated competency assessments, and high-scalability enterprise solutions.

---

## 🚀 Key Features & Highlights

- **Modern Glassmorphic Navbar & Hero Section:** Integrated with rich mega-dropdown navigation, live AI code execution widgets, 3D tilt interaction physics, and real-time telemetry metrics.
- **Enterprise Client Showcase:** High-performance, infinite scrolling marquee featuring global enterprise partners with interactive hover states.
- **Product Pillars Architecture:**
  - **Assessment Platform:** Interactive code execution sandbox with real-time proctoring and multi-language support (TypeScript, Python, Java, Go).
  - **Remote Interview Solutions:** Live pair-programming interface, audio visualizers, and instant candidate evaluation telemetry.
  - **Autonomous AI Workflows:** Automated AI developer agents handling code reviews, unit testing, and deployment pipelines.
- **Performance & Scalability Dashboard ("Why Adroit"):** Interactive SVG-based telemetry charts demonstrating deployment velocity, code quality metrics, and hiring efficiency.
- **Platform Ecosystem Grid:** High-concurrency sandbox modules, embedded intelligence cards, and deep developer analytics.
- **Interactive Lead Generation:** Dynamic multi-step modal form for enterprise demo requests and sales engagement.
- **High-Performance Animations:** Powered by Framer Motion for smooth scroll-triggered entrances, glowing gradients, and fluid layout transitions.

---

## 🛠️ Tech Stack

- **Framework:** React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Utility-first with custom glassmorphism directives)
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Build Tool:** Vite

## ⚡ Getting Started Locally

### Prerequisites
Make sure you have Node.js (v18+) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Dhruv-hub26/adroit-official-web.git](https://github.com/Dhruv-hub26/adroit-official-web.git)
   cd adroit-official-web
Install dependencies:

Bash
npm install
Start the development server:

Bash
npm run dev
Open your browser and navigate to http://localhost:5173.

📦 Build for Production
To create an optimized production build:

Bash
npm run build
To preview the production build locally:

Bash
npm run preview
